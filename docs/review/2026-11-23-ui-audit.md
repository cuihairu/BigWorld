## 二、逐界面审核（impeccable 维度）

### 1. worldeditor
- **BLOCKED** —— 缺：**Windows + VS（MSVC）+ MFC 构建/显示环境**。
- 取证：仅 `BW_CMAKE_TARGET=tools` 生成（`programming/bigworld/build/cmake/BWConfiguration_tools.cmake:110`）；MFC 头（`afxwin.h`/`afxdhtml.h`/`afxpriv.h`）在 Linux 无、亦无 MSVC 编译器；本仓 Linux `make el7`（server）构建图不含本目标（`programming/bigworld/server/Makefile` 无引用）；`game/bin` 下**无任何** `worldeditor*` 构建产物。
- 结论：无法构建 → 无法运行 → 无法截图。impeccable 维度（层级/排版/对比度 a11y/布局/边界态）需渲染后的窗口，**不能以静态代码代真**。未跑 → 无截图、无分数、不伪造。

### 2. modeleditor
- **BLOCKED** —— 缺：同上（Windows + VS + MFC 构建/显示环境）。
- 取证：`BWConfiguration_tools.cmake:111`；`tools/modeleditor/pch.hpp` 含 MFC 头；Linux 构建图无引用；`game/bin` 无 `modeleditor*`。
- 结论：同上，无法构建/运行/截图。

### 3. particle_editor
- **BLOCKED** —— 缺：同上（Windows + VS + MFC 构建/显示环境）。
