## 写法约定

- 文件名：`adr-<四位编号>-<短横线短名>.md`。
- 必备小节：**状态**（已接受/已替代/提议中 + 日期）、**背景**（要解决的问题与
  约束）、**决策**（一句话可执行结论 + 要点）、**取舍**（被否掉的备选与理由）、
  **后果**（正面 / 代价与风险 / 触发的后续）。
- 决策涉及的长文证据（迁移台账、构建分析等）只链接，不复述。
